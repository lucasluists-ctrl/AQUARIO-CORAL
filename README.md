# 🐠 Aquário Coral

O **Aquário Coral** é um projeto acadêmico de desenvolvimento Front-end que apresenta o site de uma empresa fictícia de aquário. A proposta é oferecer aos visitantes informações sobre o espaço, suas espécies aquáticas, estrutura e serviços.

O site foi desenvolvido com o objetivo de facilitar o acesso às informações do aquário e proporcionar uma experiência de navegação simples e intuitiva.

## 🌊 Sobre o projeto

O site permite que os visitantes conheçam melhor o Aquário Coral, explorem algumas das espécies presentes no ambiente, consultem informações sobre a localização e os funcionários e tenham acesso aos canais de atendimento.

## 📄 Páginas do site

- **Início:** página principal, com apresentação do Aquário Coral e acesso às demais áreas do site.
- **Sobre:** apresenta a história, os objetivos e os compromissos do aquário.
- **Ingressos:** disponibiliza informações sobre os tipos de ingresso, valores e formulário de compra.
- **Estrutura:** apresenta os ambientes do aquário, algumas espécies aquáticas, a localização e os funcionários.
- **Ajuda:** reúne informações de contato e perguntas frequentes para auxiliar os visitantes.

## 💻 Tecnologias utilizadas

- HTML5 — estruturação das páginas.
- CSS3 — estilização e organização dos elementos visuais.

## 🎯 Objetivo acadêmico

Este projeto foi desenvolvido como parte das atividades da disciplina de Front-end, com a finalidade de aplicar os conhecimentos adquiridos na construção de páginas web, utilizando HTML e CSS.

O desenvolvimento também permitiu praticar a organização de arquivos, a criação de layouts, a navegação entre páginas e a utilização de imagens e elementos visuais.
